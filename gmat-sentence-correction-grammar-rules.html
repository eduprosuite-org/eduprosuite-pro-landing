1. Strict Parallelism & Correlative Conjunctions

The GMAT tests parallel grammatical architecture relentlessly. If $X$ starts with a prepositional phrase ('in Europe'), $Y$ must mirror it ('in Asia').

$$\text{Either } X \text{ or } Y, \quad \text{Neither } X \text{ nor } Y, \quad \text{Not only } X \text{ but also } Y, \quad \text{Both } X \text{ and } Y \\ \text{Rule: } X \text{ and } Y \text{ MUST share identical grammatical form (Noun with Noun, Gerund with Gerund, Clause with Clause).}$$
⚠️ Common Candidate Trap: Unbalanced correlatives: 'Not only did he run, but also swam' is INCORRECT; it must balance verbs identically ('Not only did he run, but he also swam').
💡 Why This Step? (Curriculum Rationale): Symmetrical syntactic structures minimize cognitive processing load in complex executive communications.

2. Pronoun Ambiguity & 'Which' vs. 'That'

On the GMAT, a pronoun like 'it' or 'they' must have a single, unambiguous, non-possessive noun antecedent.

$$\text{'Which' } \implies \text{Preceded by a comma; introduces a NON-ESSENTIAL modifier.} \\ \text{'That' } \implies \text{No comma; introduces an ESSENTIAL restrictive clause.} \\ \text{Rule: A pronoun on the GMAT CANNOT refer to an entire clause or possessive noun!}$$
⚠️ Common Candidate Trap: Referring 'which' to an entire previous clause: In 'The company increased sales, which pleased the board', 'which' is WRONG on the GMAT because 'which' can only modify the noun immediately preceding it ('sales')!
💡 Why This Step? (Curriculum Rationale): Enforces zero ambiguity in institutional contract and executive report writing.

3. The Command Subjunctive & Conditional Structures

The subjunctive mood strips off all third-person singular endings ($-s$) and auxiliaries ('should'). Always uses the bare infinitive base verb.

$$\text{Bossy Verbs (demand, require, propose, insist, suggest) } + \text{THAT} + \text{Subject} + \text{BASE VERB} \\ \text{'The board demanded that he RESIGN (not resigns, not resigned, not to resign).'}$$
⚠️ Common Candidate Trap: Using 'should' in command subjunctive: Writing 'The CEO insisted that she should be present' is redundant and incorrect on the GMAT; write 'insisted that she BE present'.
💡 Why This Step? (Curriculum Rationale): The subjunctive conveys mandatory intent rather than indicative descriptive fact.
