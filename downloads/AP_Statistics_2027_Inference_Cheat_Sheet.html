1. Inference Procedure Master Decision Matrix (Units 6–9)
Variable Type Samples / Groups Procedure Name Test Statistic Formula Critical Assumptions
Categorical (Proportions) 1 Sample 1-Sample z-test for p z = (p̂ - p₀) / √(p₀(1-p₀)/n) Random sample; 10% condition; np₀ ≥ 10 and n(1-p₀) ≥ 10.
Categorical (Proportions) 2 Independent Samples 2-Sample z-test for p₁ - p₂ z = (p̂₁ - p̂₂) / √(p̂c(1-p̂c)(1/n₁ + 1/n₂)) Independent random samples; 10% condition; pooled counts ≥ 10.
Quantitative (Means) 1 Sample (σ unknown) 1-Sample t-test for μ t = (x̄ - μ₀) / (s / √n), df = n - 1 Random sample; 10% condition; Normal population or n ≥ 30 (CLT).
Quantitative (Means) Paired Data (Before/After) Matched Pairs t-test for μ_d t = (x̄_d - 0) / (s_d / √n), df = n - 1 Random paired sample; differences approximately normal or n ≥ 30.
Quantitative (Means) 2 Independent Samples 2-Sample t-test for μ₁ - μ₂ t = ((x̄₁ - x̄₂) - 0) / √(s₁²/n₁ + s₂²/n₂) Independent random samples; both populations normal or n₁, n₂ ≥ 30.
Categorical Frequencies 1 Variable across multiple categories Chi-Square Goodness of Fit χ² = Σ (O - E)² / E, df = k - 1 Random sample; all expected counts E ≥ 5.
Two Categorical Variables Single Sample (Association) Chi-Square Test of Independence χ² = Σ (O - E)² / E, df = (r-1)(c-1) Random sample; two-way table; all expected counts E ≥ 5.
Bivariate Quantitative Paired (x, y) coordinates Linear Regression t-test for slope β t = (b - 0) / SE_b, df = n - 2 LINER conditions: Linear, Independent, Normal residuals, Equal variance, Random.
2. FRQ Official Rubric Sentence Frames
A. Interpreting Confidence Level (e.g. 95%):
"If this sampling procedure were repeated many times, approximately 95% of the resulting confidence intervals would capture the true population [proportion/mean] of [parameter in context]."
B. Interpreting P-Value in Context:
"Assuming that the null hypothesis is true (that the true [parameter] equals [H₀ value]), there is a [p-value] probability of obtaining a test statistic as extreme as or more extreme than the observed one purely due to sampling variability."
C. Stating Inference Conclusion (Hypothesis Testing):
"Because our p-value [e.g. 0.021] is less than α = 0.05, we reject the null hypothesis. There is convincing statistical evidence that [restate Hₐ in context]."
💡 Exam Day Tip: Never say "we accept H₀" or "H₀ is proven true." College Board AP® graders penalize this phrasing. Always state "we fail to reject H₀."
