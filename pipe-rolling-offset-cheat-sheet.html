1. Simple 45° Offset Calculations & Multipliers

A $45^\circ$ offset forms an isosceles right triangle where the Set equals the Run. The Travel (hypotenuse) is always $\text{Set} \times \sqrt{2} = \text{Set} \times 1.414$.

$$\text{Travel} = \text{Offset (Set)} \times 1.414, \quad \text{Run} = \text{Set} \quad (\text{for } 45^\circ \text{ bends}), \quad \text{Cut Length} = \text{Travel} - (\text{Take-out } 1 + \text{Take-out } 2)$$
⚠️ Common Job-Site Trap Alert: Forgetting fitting take-outs: If Travel is $24"$ and your two $45^\circ$ elbows have a take-out of $1.5"$ each, your actual cut pipe length is $24 - 3 = 21"$!
💡 Why This Step? (Trade Standard): The center-to-center travel length extends into the hub of both fittings; cutting the pipe to raw travel length makes the assembly too long.

2. Rolling Offsets (Three-Dimensional Bends)

A rolling offset changes both elevation (Rise) and horizontal plane (Roll). Solve the 2D base triangle first using Pythagorean theorem to find True Offset, then multiply by 1.414.

$$\text{True Offset} = \sqrt{\text{Rise}^2 + \text{Roll}^2}, \quad \text{Travel} = \text{True Offset} \times 1.414 = \sqrt{\text{Rise}^2 + \text{Roll}^2 + \text{Run}^2}$$
⚠️ Common Job-Site Trap Alert: Adding Rise and Roll before squaring: $\sqrt{\text{Rise}^2 + \text{Roll}^2} \neq \text{Rise} + \text{Roll}$! Square each leg independently first.
💡 Why This Step? (Trade Standard): Three-dimensional Euclidean distance formula is $d = \sqrt{\Delta x^2 + \Delta y^2 + \Delta z^2}$.

3. Parallel Offsets & Pipe Spread Multipliers

When running parallel pipes through a turn or offset, the outer pipe must travel farther than the inner pipe to maintain equal spacing (spread).

$$\Delta \text{Travel} = \text{Spread} \times \tan(22.5^\circ) = \text{Spread} \times 0.414 \quad (\text{for } 45^\circ \text{ parallel lines})$$
⚠️ Common Job-Site Trap Alert: Making all parallel travel pieces identical: If all pipes are cut to the same length, the parallel spacing will pinch and collide at the elbows.
💡 Why This Step? (Trade Standard): Maintaining constant perpendicular distance between parallel curves requires radial compensation.
