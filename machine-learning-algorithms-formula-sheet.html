MODULE 1

Support Vector Machines (SVM) Dual Problem & Kernel Trick

$$\max_{\alpha} \sum_{i=1}^n \alpha_i - \frac{1}{2}\sum_{i=1}^n \sum_{j=1}^n \alpha_i \alpha_j y_i y_j K(x_i, x_j) \quad \text{s.t. } 0 \le \alpha_i \le C, \ \sum_{i=1}^n \alpha_i y_i = 0$$

📘 Mathematical & Clinical Mechanics

The dual formulation allows replacing high-dimensional dot products $\phi(x_i)^T \phi(x_j)$ with Mercer kernel functions $K(x_i, x_j) = \exp(-\gamma \|x_i - x_j\|^2)$.

⚠️

Candidate & Practitioner Trap Alert

Failing to scale input features before RBF SVM: Features with large numerical ranges dominate Euclidean distances, rendering other predictors useless.

Decision Tree Splitting Metrics: Gini Impurity vs Shannon Entropy

$$\text{Gini: } I_G(D) = 1 - \sum_{i=1}^c p_i^2, \quad \text{Entropy: } H(D) = -\sum_{i=1}^c p_i \log_2(p_i), \quad \text{Information Gain} = I(D) - \sum_{v} \frac{|D_v|}{|D|} I(D_v)$$

📘 Mathematical & Clinical Mechanics

Gini is computationally faster as it avoids logarithmic computations, yielding nearly identical tree structures to Information Gain.

⚠️

Candidate & Practitioner Trap Alert

High-cardinality feature bias in Information Gain: Features with unique values (e.g., User ID) yield maximum Information Gain; Gain Ratio must be used to normalize by split intrinsic info.
