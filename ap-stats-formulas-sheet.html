1. Descriptive Statistics & Summary Measures

Unit 1 and Unit 2 rely heavily on single-variable and bivariate summaries. The formula sheet provides equations for sample mean, variance, standard deviation, and the least-squares regression line.

Sample Mean & Standard Deviation

$$\bar{x} = \frac{1}{n} \sum x_i = \frac{\sum x_i}{n}$$
$$s_x = \sqrt{\frac{1}{n-1} \sum (x_i - \bar{x})^2}$$

Variable Key: $n$ is the sample size, $x_i$ represents each individual data observation, and $n-1$ represents the degrees of freedom for sample variance.

⚠️ Key Calculation Standard (Degrees of Freedom): Always divide by $n-1$, never $n$, when calculating sample standard deviation $s_x$. Dividing by $n$ underestimates population variability (biased estimator).

Least-Squares Regression Line (LSRL)

$$\hat{y} = b_0 + b_1 x$$
$$b_1 = r \left(\frac{s_y}{s_x}\right), \quad b_0 = \bar{y} - b_1 \bar{x}$$

Interpretation on FRQ: The slope $b_1$ indicates the predicted change in the response variable $\hat{y}$ for each 1-unit increase in the explanatory variable $x$. You must always state "predicted" or "estimated" to earn full credit.

2. Probability & Discrete Random Variables

Probability rules on the AP exam govern independent events, conditional probabilities, and binomial/geometric distributions.

Addition Rule & Conditional Probability

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$
$$P(A \mid B) = \frac{P(A \cap B)}{P(B)}$$
💡 Why This Step? Subtracting $P(A \cap B)$ in the general addition rule prevents double-counting the overlap when events $A$ and $B$ are not mutually exclusive (disjoint). If $A$ and $B$ are mutually exclusive, $P(A \cap B) = 0$.

Binomial Distribution Parameters (BINS Conditions)

A random variable $X \sim \text{Binomial}(n, p)$ represents the number of successes in $n$ independent Bernoulli trials with constant probability $p$:

$$\mu_X = np, \quad \sigma_X = \sqrt{np(1-p)}$$
$$P(X = k) = \binom{n}{k} p^k (1-p)^{n-k}$$

3. Sampling Distributions & Standard Errors

The standard error formula changes depending on whether you are working with categorical data (proportions) or quantitative data (means).

Parameter Statistic Standard Deviation of Statistic Standard Error (SE)
One Proportion ($p$) $\hat{p}$ $$\sigma_{\hat{p}} = \sqrt{\frac{p(1-p)}{n}}$$ $$\text{SE}_{\hat{p}} = \sqrt{\frac{\hat{p}(1-\hat{p})}{n}}$$
Difference of Proportions ($p_1 - p_2$) $\hat{p}_1 - \hat{p}_2$ $$\sqrt{\frac{p_1(1-p_1)}{n_1} + \frac{p_2(1-p_2)}{n_2}}$$ $$\sqrt{\frac{\hat{p}_1(1-\hat{p}_1)}{n_1} + \frac{\hat{p}_2(1-\hat{p}_2)}{n_2}}$$
One Mean ($\mu$) $\bar{x}$ $$\sigma_{\bar{x}} = \frac{\sigma}{\sqrt{n}}$$ $$\text{SE}_{\bar{x}} = \frac{s_x}{\sqrt{n}}$$
Difference of Means ($\mu_1 - \mu_2$) $\bar{x}_1 - \bar{x}_2$ $$\sqrt{\frac{\sigma_1^2}{n_1} + \frac{\sigma_2^2}{n_2}}$$ $$\sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}$$

4. General Inference Formula Framework

Every single confidence interval and hypothesis test in AP Statistics follows the exact same universal template:

Universal Confidence Interval Template

$$\text{Confidence Interval} = \text{Statistic} \pm (\text{Critical Value}) \times (\text{Standard Error})$$

For proportions, critical value is $z^*$. For means when $\sigma$ is unknown, critical value is $t^*$ with $df = n - 1$.

Universal Test Statistic Template

$$\text{Test Statistic} = \frac{\text{Statistic} - \text{Null Parameter Value}}{\text{Standard Error of Statistic}}$$

5. Calculator Syntax vs College Board Rubrics

While the TI-84 Plus CE or Casio fx-9750GIII calculates $p$-values automatically, College Board AP readers will award zero points if you only write 1-PropZTest(...) = 0.034. You must:

  1. State the formal name of the test: "One-sample $z$-test for a population proportion".
  2. State hypotheses: $H_0: p = 0.50$ vs $H_a: p > 0.50$.
  3. Verify all 3 conditions: Randomization, 10% condition ($10n < N$), and Large Counts ($np_0 \ge 10, n(1-p_0) \ge 10$).
  4. Show the substituted formula with numbers before stating the test statistic and $p$-value.
