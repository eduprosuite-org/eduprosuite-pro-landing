Step 1: STATE — Hypotheses & Parameter Definitions

Every hypothesis test begins by clearly identifying the population parameter of interest and setting up the null ($H_0$) and alternative ($H_a$) hypotheses.

Hypothesis Notation Template

$$H_0: \mu = \mu_0 \quad \text{vs} \quad H_a: \mu > \mu_0 \quad (\text{or } \mu < \mu_0, \text{ or } \mu \ne \mu_0)$$

$$H_0: p = p_0 \quad \text{vs} \quad H_a: p > p_0 \quad (\text{or } p < p_0, \text{ or } p \ne p_0)$$

⚠️ Critical Scoring Standard: Hypotheses must ALWAYS be written using population parameters ($\mu, p, \beta$), NEVER sample statistics ($\bar{x}, \hat{p}, b$). Writing $H_0: \bar{x} = 25$ results in an automatic zero for Step 1.

Step 2: PLAN — Test Name & Condition Verification

You must state the specific inference procedure by name and explicitly check all three mathematical conditions:

  1. Random Condition: Data must come from a well-designed random sample or randomized experiment to eliminate sampling bias.
  2. 10% Independence Condition (Sampling without replacement): Sample size must satisfy $10n < N$ so that sampling without replacement does not distort the standard error.
  3. Normality / Large Counts Condition:
    • For proportions: $n p_0 \ge 10$ and $n(1-p_0) \ge 10$ (using the null value $p_0$, not $\hat{p}$).
    • For means: Sample size $n \ge 30$ (Central Limit Theorem) or the population distribution is stated as normal with no extreme outliers/skewness.

Step 3: DO — Test Statistic & P-Value Derivation

Calculate the standardized test statistic and derive the resulting $P$-value from the appropriate reference distribution (Normal $Z$, Student's $t$, or $\chi^2$).

$$z = \frac{\hat{p} - p_0}{\sqrt{\frac{p_0(1-p_0)}{n}}}, \qquad t = \frac{\bar{x} - \mu_0}{\frac{s_x}{\sqrt{n}}}$$

Always report: (1) Test statistic ($z$ or $t$), (2) Degrees of freedom if using $t$, and (3) Exact $P$-value (e.g., $P\text{-value} = 0.0214$).

Step 4: CONCLUDE — Two-Sentence Context Template

To score full credit on Step 4, your conclusion must compare the $P$-value to the significance level $\alpha$ and state the conclusion in the context of the problem.

When $P\text{-value} < \alpha$ (Reject $H_0$):

"Because the $P$-value ($0.0214$) is less than our significance level $\alpha = 0.05$, we reject the null hypothesis $H_0$. There is convincing statistical evidence that [insert alternative hypothesis in authentic context]."

When $P\text{-value} \ge \alpha$ (Fail to Reject $H_0$):

"Because the $P$-value ($0.1432$) is greater than our significance level $\alpha = 0.05$, we fail to reject the null hypothesis $H_0$. There is not convincing statistical evidence that [insert alternative hypothesis in authentic context]."

Frequently Asked Questions

❓ What happens if alpha level is not given?

If no significance level $\alpha$ is explicitly stated in the problem, use $\alpha = 0.05$ as the universal standard default.

\n

❓ Can I say 'We accept the null hypothesis'?

NO! You can NEVER say 'accept the null'. You can only 'fail to reject the null'. Accepting $H_0$ implies proving $H_0$ is true, which hypothesis tests never do.
