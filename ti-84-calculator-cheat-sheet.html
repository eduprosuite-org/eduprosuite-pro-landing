1. Solving Any System of Equations in 10 Seconds via rref()

Reduced Row Echelon Form immediately solves systems of 2, 3, or 4 linear equations with zero manual substitution or elimination algebra.

$$\text{[2nd] [MATRIX] } \rightarrow \text{EDIT [A]} \rightarrow \text{Set } 3 \times 4 \rightarrow \text{Enter coefficients} \rightarrow \text{[2nd] [QUIT]} \rightarrow \text{[2nd] [MATRIX] MATH } \rightarrow \text{B:rref([A])}$$
⚠️ Student Trap Alert: Entering right-hand constants on wrong side: The system must be in standard form $ax + by = c$; if given $ax + by - c = 0$, move $c$ to the right side first!
💡 Why This Step? (Pedagogical Rationale): Row operations systematically eliminate pivot variables, yielding the identity matrix with solution values in the final column.

2. Normal Distributions & Inverse Probability Keystrokes

Never use 1:normalpdf for intervals; normalpdf only gives curve height! Use 1E99 ($10^{99}$) for $\infty$ and -1E99 for $-\infty$.

$$\text{Probability: [2nd] [DISTR] } \rightarrow \text{2:normalcdf(lower, upper, }\mu, \sigma) \\ \text{Cutoff Value: [2nd] [DISTR] } \rightarrow \text{3:invNorm(area, }\mu, \sigma, \text{LEFT)}$$
⚠️ Student Trap Alert: Using normalpdf instead of normalcdf: Continuous distributions have probability zero at exact single points ($P(X=k) = 0$); always use normalcdf for areas!
💡 Why This Step? (Pedagogical Rationale): Probability in continuous distributions is the integral area under the probability density curve.

3. Finding All Polynomial Roots with PlySmlt2

Instantly finds real and complex roots of quadratic, cubic, and quartic polynomials on AP Calculus and SAT exams without manual factoring.

$$\text{[APPS] } \rightarrow \text{PolySmlt2 } \rightarrow \text{1:Poly Root Finder } \rightarrow \text{Select Degree } (2, 3, 4) \rightarrow \text{Enter coefficients } a_n$$
⚠️ Student Trap Alert: Missing zero coefficients: If polynomial is $x^3 - 4x + 5 = 0$, you MUST enter $0$ for the $x^2$ coefficient ($a_2 = 0$)!
💡 Why This Step? (Pedagogical Rationale): Degree order determines array indexing; skipping a term shifts powers down by one.
