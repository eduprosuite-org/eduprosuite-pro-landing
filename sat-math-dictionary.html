Circle Equation in Standard Form

An equation defining a circle with center (h, k) and radius r.

(x - h)^2 + (y - k)^2 = r^2
⚠️ Exam Trap Alert: Be ready to complete the square if given general form x^2 + y^2 + Ax + By + C = 0.

Discriminant (b^2 - 4ac)

Determines the number of real solutions of ax^2 + bx + c = 0. If > 0, 2 distinct solutions; if = 0, 1 real solution; if < 0, 0 real solutions.

Delta = b^2 - 4ac
⚠️ Exam Trap Alert: When a question says 'no real solutions', set b^2 - 4ac < 0 immediately.

Exponential Growth & Decay

Model represented by y = a(1 +- r)^t or y = a(b)^t where a is initial value and r is growth/decay rate.

y = a(1 + r)^t
⚠️ Exam Trap Alert: Watch unit time conversions (e.g. doubles every 3 hours vs per hour).

Linear System Solutions

Two lines y = m1*x + b1 and y = m2*x + b2 have: 1 solution if m1 != m2; no solution if m1 == m2 and b1 != b2 (parallel); infinite solutions if m1 == m2 and b1 == b2 (coincident).

Pythagorean Triples

Integer sets satisfying a^2 + b^2 = c^2. Crucial common triples: 3-4-5, 5-12-13, 8-15-17, 7-24-25 and their multiples.

Quadratic Vertex Formula

The x-coordinate of the vertex of parabola y = ax^2 + bx + c.

x_v = -b / (2a)
⚠️ Exam Trap Alert: Substitute x_v back into the original function to find minimum or maximum value.

Similar Triangles

Triangles with identical corresponding angles and proportional side lengths. Side ratio k implies area ratio k^2.

⚠️ Exam Trap Alert: If side lengths double, the area quadruples (2^2 = 4).

Parabolic form revealing the vertex coordinates (h, k) directly.

y = a(x - h)^2 + k
