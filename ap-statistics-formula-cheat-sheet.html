1. Inference Test Decision Framework (1-Prop, 2-Prop, T-Test, Chi-Square)

If data is recorded in pairs for the same subject (e.g., Before vs. After), analyze the single column of differences $d = x_1 - x_2$ using a Paired $t$-test (NOT a two-sample test).

$$\text{Means (Quantitative): One sample } t\text{-test}, \text{ Two-sample } t\text{-test}, \text{ Paired } t\text{-test} \\ \text{Proportions (Categorical): 1-prop } z\text{-test}, \text{ 2-prop } z\text{-test}, \text{ Chi-Square GOF (1 variable)}, \text{ Chi-Square Indep (2 variables)}$$
⚠️ Student Trap Alert: Calling a paired test a two-sample test: Paired data is a ONE-sample test on differences $d$ with $\text{df} = n-1$.
💡 Why This Step? (Pedagogical Rationale): Paired testing eliminates between-subject variability, dramatically boosting statistical power.

2. Type I Error, Type II Error & Statistical Power

To increase power without increasing $\alpha$, increase sample size $n$. Type I is a false positive (convicting an innocent person); Type II is a false negative (releasing a guilty person).

$$P(\text{Type I Error}) = \alpha = P(\text{Reject } H_0 \mid H_0 \text{ is true}), \quad P(\text{Type II Error}) = \beta = P(\text{Fail to reject } H_0 \mid H_0 \text{ is false}), \quad \text{Power} = 1 - \beta$$
⚠️ Student Trap Alert: Saying 'accept the null hypothesis': We NEVER accept $H_0$; we only 'fail to reject' $H_0$ due to lack of convincing evidence.
💡 Why This Step? (Pedagogical Rationale): Absence of evidence is not evidence of absence; failing to disprove $H_0$ does not prove it is universally true.

3. Linear Regression Inference ($b_1 \pm t^* SE_{b_1}$)

The slope $b_1$ represents the predicted change in $y$ for each 1-unit increase in $x$. Coefficient of determination $r^2$ is the percentage of variation in $y$ explained by the linear model with $x$.

$$\hat{y} = b_0 + b_1 x, \quad t = \frac{b_1 - 0}{SE_{b_1}}, \quad \text{df} = n - 2, \quad s = \sqrt{\frac{\sum (y_i - \hat{y}_i)^2}{n-2}}$$
⚠️ Student Trap Alert: Describing correlation as causation: Strong $r$ does NOT prove $x$ causes $y$ unless derived from a randomized controlled experiment.
💡 Why This Step? (Pedagogical Rationale): Confounding lurking variables can create spurious correlations between unrelated observational variables.
