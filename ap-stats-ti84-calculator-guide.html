1. Probability Distributions [2nd] [VARS] (DISTR)

Command Keystrokes Input Syntax When to Use
normalcdf [2nd] [VARS] -> 2 (lower, upper, $\mu$, $\sigma$) Find area under normal curve between two values. Use $-1\text{E}99$ or $1\text{E}99$ for $\pm\infty$.
invNorm [2nd] [VARS] -> 3 (area, $\mu$, $\sigma$, [LEFT/CENTER/RIGHT]) Find $z^*$ or $x$ value for a given percentile area.
binompdf [2nd] [VARS] -> A (trials, $p$, $x$) Find probability of exactly $x$ successes: $P(X = k)$.
binomcdf [2nd] [VARS] -> B (trials, $p$, $x$) Find cumulative probability of at most $x$ successes: $P(X \le k)$.
tcdf [2nd] [VARS] -> 6 (lower, upper, $df$) Find probability area under Student's $t$ curve with degrees of freedom $df$.

2. Hypothesis Tests [STAT] -> TESTS

1-PropZTest (Menu Option 5)

Inputs: $p_0$ (null proportion), $x$ (number of successes, must be an integer), $n$ (sample size), prop ($ e p_0, < p_0, > p_0$).

Output: $z$ (standardized test statistic), $p$ ($P$-value), $\hat{p}$ (sample proportion).

2-SampTTest (Menu Option 4)

Inputs: Data in Lists or Summary Stats ($\bar{x}_1, s_1, n_1, \bar{x}_2, s_2, n_2$), Pooled: Always select NO.

Output: $t$ test statistic, $p$-value, calculated degrees of freedom ($df$).

🚨 Critical AP Exam Note on Pooled T-Test: Never select "Pooled: YES" for two-sample $t$-tests on the AP exam unless population variances are explicitly proven equal. Always select "Pooled: NO".

3. Linear Regression & Residuals [STAT] [CALC] 8

Always use LinReg(a+bx) (Option 8), NOT Option 4, to conform with College Board notation where $b$ represents slope.

  1. Enter explanatory $x$ data into $L_1$ and response $y$ data into $L_2$.
  2. Press [STAT] -> CALC -> 8: LinReg(a+bx).
  3. Turn DiagnosticOn: Press [2nd] [0] (CATALOG), scroll down to DiagnosticOn, and press [ENTER] twice to display correlation coefficient $r$ and $r^2$.
  4. Residuals are automatically saved to list RESID ([2nd] [STAT] -> NAMES -> RESID).

Frequently Asked Questions

❓ Can I clear calculator RAM before entering the exam?

Proctors will instruct you to clear calculator RAM before Section I. Practice re-enabling DiagnosticOn and setting RADIAN/DEGREE modes beforehand.

\n

❓ What if x is not an integer in 1-PropZTest?

If you calculate $x = n \times \hat{p}$ and get a decimal (e.g., 42.6), you must round to the nearest whole integer (43), or the TI-84 will give a DOMAIN ERROR.
