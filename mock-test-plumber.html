People Also Ask (PAA) — Journeyman Plumber Exam FAQ

What is the minimum passing score for the Journeyman Plumber exam?

Most state testing boards require a minimum score of 70% (or 75% in select jurisdictions) across code questions, isometric drawing interpretation, and trade calculations.

How do you calculate a 45-degree rolling offset in plumbing?

First compute the True Offset using the Pythagorean theorem: True Offset = √(Rise² + Roll²). Then multiply True Offset by 1.414 to find the Travel distance between fitting centers, then subtract fitting take-offs.

What is the difference between an air break and an air gap?

An air gap is an unobstructed vertical physical space between the water supply outlet and flood level rim. An air break discharges indirectly into a fixture below the flood rim but above the trap seal.
